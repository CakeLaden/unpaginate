# Audiobook selection preferences (Kyle)

Use these preferences when curating “classic picks” from an `unpaginate` results list.

## Core taste

- **Primary lane**: classic literature and “modern classics.”
- **Nonfiction**: include it when it’s **canonical / influential** (history, philosophy, cultural criticism, major science writing, etc.).
- **Sci‑fi / fantasy**: include if it’s **well‑renowned** (genre-canon, frequently recommended, culturally influential). Avoid random/unknown SFF unless there’s a strong “classic” signal.

## Selection criteria (include when *any* apply)

- **Pre‑1960 originals**: prioritize items whose **original book/text** was published **before 1960** (ignore audiobook production date).
  - For epics / scripture / very old texts, treat the underlying work as “pre‑1960” and note that the audiobook is a modern translation/edition/retelling.
- **Famous / respected authors**: include works by widely recognized authors in the classic/modern-classic canon.
  - If a famous author appears in the list (example discussed: **Kurt Vonnegut**), **include all of their works present** rather than cherry-picking one.
- **“Greatest books” footprint**: include books that appear on reputable “best novels/books” lists or that are widely taught/anthologized.

## Inclusion bias / philosophy

- **Err on inclusion**: prefer including too much vs. too little when uncertain.
- **Title collisions**: verify author/title matches when names overlap (e.g., multiple books with the same title by different authors).

## Output format preferences (for curated reports)

When generating a curated HTML report:

- **Only include the selected contenders** (filtered rows).
- Add two columns:
  - **`pickDescription`**: short, plain-language description of why it might be enjoyable.
  - **`whyIncluded` / works cited**: links to reputable references (Britannica, major publications’ lists, award pages, Wikipedia for publication-year verification, etc.) plus a brief explanation of which criteria triggered inclusion.
